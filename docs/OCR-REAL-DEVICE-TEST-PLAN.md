# OCR 真实环境只读验证方案（v3.0.0 发布前验收，准备稿）

> **状态：准备稿 — 未获用户授权前不执行任何真实微信操作（含只读截图）。**
> 本文档只描述计划与授权门槛，不代表已执行；本轮（发布前验收 / task-25）只做离线与 mock 验证，
> 不读取真实聊天、不向真实联系人发送、不采集截图。
> 参考任务书：`DSH_v3.0.0_隐私整改与实机验收准备_完整提示词.md` §9（本轮只准备不执行）、§11 与 §12。
>
> **授权模式分四层**：`offline-replay`（离线回放，已在本轮完成）→ `passive-capture`（真实窗口被动截图，需单独授权）
> → `interactive-read`（交互式读取：打开会话/滚动，需再次授权）→ `send-mode`（真实发送，需最强授权且本轮禁止）。
> 每一层都是下一层的**前置条件**；任一层的安全项失败立即停止并回退，不允许跳级。

## 1. 目的

用**真实 Windows 与真实微信窗口**验证 v3.0.0 OCR 读取链路（截图 → OCR → 气泡归属 → 消息提取 → 身份/去重 → ack → 引擎入站）在真实字体、真实窗口尺寸、真实 DPI 下是否可用，并回答三个问题：

1. 真实截图下 OCR 的**漏读率/假消息率/归属错误率**是否可接受，是否达到「相对 v0.2.8 有可测量改善」；
2. 消息身份与去重（同一消息不重投、连发同文算两条、滚动不重触发、重启不重发）在真实窗口里是否成立；
3. 只读隔离是否从代码层保证：**不会发生任何真实发送**。

## 2. 前置条件（全部满足才可开始）

## 5. 判定标准

- **安全项（任一失败即中止）**：出现任何真实发送 / 发送脚本被调用 / 读取真实私人会话 → 立即停止，回退 `legacy` 或关闭通道。
- **功能项（建议阈值）**：
  - 漏读率 ≤ 10%（虚构语料 20 条消息内）；
  - 假消息率 = 0（不得把头像/系统提示当消息）；
  - 归属错误 = 0（左右判定错误视为 P0，必须修复后才可继续）；
  - 重复投递 = 0（T3/T8/T12）；
  - 联系人串聊 = 0；
  - 消息 id 跨帧稳定（同一 pending 重放 id 不变）。
- **性能项**：单帧截图+OCR P50 ≤ 1.5s、P95 ≤ 3s（仅记录，不阻断；RapidOCR 第二引擎按需）。

### 5.1 人工标准答案与指标定义（必须由人工标注，不得只看自动数字）

1. **人工标准答案（gold）**：对每个测试场景，人工逐条记录「屏幕上真实可见的消息」= 文本、方向（左/右）、顺序、时间。
   只使用虚构会话内容；gold 文件存本机 `dev-notes/`（gitignore），不入库。
2. **漏报（false negative）**：gold 中存在、但 v3 未投递的消息条数 / gold 总条数。
3. **误报（false positive）**：v3 投递了、但 gold 中不存在（OCR 幻觉、系统提示、头像文字等）的条数；**目标为 0**。
4. **归属错误**：左右判定与 gold 不一致的条数；**目标为 0**，出现即 P0。
5. **CER（字符错误率）**：逐条消息按 `compareKey` 归一后计算编辑距离 / gold 字符数，取平均；
   公式：`CER = Σ edit_distance(hyp, gold) / Σ len(gold)`。
6. **整句准确率**：归一化后完全相同（或仅差标点）的消息条数 / gold 总条数。
7. **重复投递**：同一 gold 消息对应 >1 次投递的次数；**目标为 0**。
8. **报告口径**：必须写「样本量、场景、DPI/分辨率、微信版本、人工标注人、日期」；样本 < 20 条时不得给出「准确率 x%」的强结论，
   只能写「未达统计意义」。

## 6.5 已读、焦点与其他副作用（必须提前告知用户）

- **L1 被动截图**：读取窗口像素通常不改变微信状态；但截图 API（PrintWindow/屏幕拷贝）可能导致窗口重绘，理论上不影响已读。
- **L2 交互读取**：打开会话/滚动会**改变「已读」标记**、抢焦点、可能触发微信自身的「正在输入/已读回执」表现；
  这是「只读 ≠ 无副作用」的部分，必须取得用户明确同意后再执行。
- **L3 发送**：真实写入测试会话，改变对方可见状态；本轮不授权、不执行。
- 插件侧副作用：`readOnlyTestMode=true` 时禁止键鼠模拟；读取使用 `-NoSearch` 或已打开会话，避免自动搜索/打开新会话。
- 用户可随时在设置页暂停/停止插件；停止后不得有任何残留自动化。

## 7. 风险与回滚

| 风险 | 影响 | 处置 |
| --- | --- | --- |
| 只读隔离有未覆盖入口 | 真实发送 | 中止；回退 `legacy`；修入口并补测试后才可重试 |
| 真实微信 OCR 与合成差异大 | 指标不达标 | 记录差异（字体/DPI/主题），给出修复方向，不强行发布 |
| 消息归属在真实长气泡上出错 | 发错人风险 | 视为 P0；`uncertain` 一律不回复，直至修复 |
| 窗口被抢占/前台切换 | 误点 | 只读模式禁止键鼠模拟，读取仅 `-NoSearch` 或已打开会话 |
| 断电/崩溃 | 状态不一致 | 数据目录可恢复；pending/ack 设计已支持重放，重启不重发待验证 |

## 8. 明确未获授权、本轮不会执行

**全局禁止（任何层级都不得做）**：

- 向真实联系人发送任何消息（含 `/test/send`、测试小号向真实好友、群聊）；
- 自动回复真实微信；
- 真实联系人压测；
- 进入私人/工作会话采集内容；
- 上传截图/聊天记录到云端（含 LLM、网盘、第三方截图工具）；
- 安装未确认的模型/依赖、push、打 tag、发布 Release、`npm publish`、改写 Git 历史；
- 启动任何会改变真实联系人可见状态的操作。

**分层禁止**：

- L1 禁止：点击、滚动、切换会话、复制粘贴、读取测试会话以外的联系人/消息。
- L2 禁止：任何发送/输入/回车/表情/转账入口；切到非测试会话；未经用户确认的「已读」副作用。
- L3 禁止：向任何非 A/B/C 测试联系人发送；任何群聊；营销/压测/批量操作。

**结论**：在当前任务书授权下，只能执行 L0（离线）；L1/L2 必须等用户单独授权，L3 默认不授权。
