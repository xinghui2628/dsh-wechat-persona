## v3.0.0-beta.1 — Developer Preview / 开发者预览版

> 这是面向开发者与尝鲜用户的**开发者预览版**，不是稳定版。真实微信环境的读取/OCR/自动发送**尚未实机验收**；
> beta 默认关闭真实通道的自动发送，避免对真实联系人造成影响。请先读 [DISCLAIMER.md](../../DISCLAIMER.md)。

### 定位

- 个人独立开发、免费开源的实验性 DSH 插件；与腾讯/微信官方无关。
- 本版重点：把「mock 可体验、离线可验证、默认安全」的 beta 交付出来，真实环境验收放到后续版本。
- 仓库是 public；`private: true` 仅表示不发布 npm。

### 主要变化（可验证）

- 版本号 `3.0.0-beta.1`（`package.json` + `src/index.ts`）；构建后 `dist` 同步。
- **默认安全 `betaSafeMode=true`**：真实通道发送在引擎/桌面通道/HTTP API/PowerShell 脚本四层被拒绝；`mock` 正常。
- 文档 beta 化：README 重写、DISCLAIMER 10 项、SECURITY 受支持版本/token 轮换/私密披露、新增 BETA-QUICKSTART / BETA-LIMITATIONS / BETA-FAQ / 本发布草稿、Issue/PR 模板增强。
- 离线验证（含 beta 闸门）：`typecheck` 0 错；`test:sandbox` **43 文件 / 725 用例**；`check-sensitive` **222 文件 0 命中**；`check-package` **197 候选 0 违规**；`verify:api` 25/25（显式关闭 beta 闸门以覆盖发送链路）；`build` exit 0。均为离线/合成验证，**不代表真实微信可用**。
  注：**以上均为离线/合成数据验证，不代表真实微信可用**。

### 最低前置

- Windows 10/11（desktop 通道）或任意平台跑 mock；Node ≥ 22；DSH 桌面版 0.2.1-rc.3+；PowerShell 5.1。
- 微信 PC 4.x + 中文（简体）OCR 语言包（仅 desktop 通道）；Python 可选（RapidOCR/基准）。

### 如何体验（不碰真实微信）

见 [BETA-QUICKSTART.md](../BETA-QUICKSTART.md)：克隆 → `npm ci --ignore-scripts` → `npm run build` → `npm run verify:api` → 以开发方式接入干净 DSH profile → mock 通道注入消息。

### ⚠️ 已知限制（醒目）

- **真实微信读取/OCR/自动发送未实机验收**；OCR 数字仅来自合成语料与离线等价，不能外推真实聊天准确率。
- `betaSafeMode` 默认开启，真实通道发送被拒；`mock` 不受影响。
- `fusion/align/tracker` 未接入生产路径；RapidOCR 新包未实测；phone-adb / windows-vm 本轮未验证。
- 从源码构建时请先 `npm run build`，否则 `dist/` 内版本号可能滞后（发布候选包已包含构建后的 `dist/`）。
- 完整清单：[BETA-LIMITATIONS.md](../BETA-LIMITATIONS.md)。

### 账号与隐私风险

- 自动化操作微信可能违反其协议，账号可能被限制/封禁；不承诺规避风控，不保证账号安全。
- 回复所需消息内容/上下文会发给你配置的 LLM 服务商；项目无遥测。
- 不要用 beta 在真实联系人上做验证性发送；不要在公开 Issue 贴真实聊天内容、截图、wxid、手机号、API Key 或含用户名的路径。

### LLM 费用

插件免费；模型调用费用由你的 LLM 服务商收取。仅做 mock 验证不产生 LLM 费用。

- 安全漏洞：请走私密披露（[SECURITY.md](../../SECURITY.md)），不要公开 Issue。
