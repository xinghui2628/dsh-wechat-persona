# Beta 常见问题（v3.0.0-beta.1）

> 10 个最常见问题。更细的安装/操作见 [使用说明.md](使用说明.md) 与 [BETA-QUICKSTART.md](BETA-QUICKSTART.md)。

### 1. 用这个会封号吗？

**有风险，且风险由你承担。** 自动化操作微信客户端可能违反《微信软件许可及服务协议》，账号可能被限制或封禁。本项目不承诺规避平台风控；请只用自己注册的小号，不要用主号。

### 2. 要花钱吗？

插件本身**免费开源**。但回复需要调用你在 DSH 里配置的 LLM 模型，**模型调用会产生费用**；云手机/虚拟机等环境也可能有成本。beta 的 mock 验证不需要付费。

### 3. 必须用真实微信吗？

不需要。**只做体验/开发时用 `mock` 通道即可**，它不接触微信，也能完整走通白名单、人格、草稿、审计等流程；真实微信能力属于 beta 预览（未实机验收）。

### 4. beta 能自动回复真实好友吗？

**beta 默认不能。** `betaSafeMode` 默认开启，真实通道的自动发送在引擎/桌面通道/HTTP API/PowerShell 脚本四层被拒绝；这是为了避免 beta 包误发。只有维护者在明确说明的版本/配置下才可能开启真实发送。

### 5. OCR 准吗？

只有**合成语料**上的离线数字（v3 eval 集 CER 21.38% / 整句 47.83%，同集 v0.2.8 为 37.37% / 28.26%）。真实聊天窗口的字体/DPI/遮挡未实机验证，不能保证准；小字体、模糊、拉伸场景更差。详见 [BETA-LIMITATIONS.md](BETA-LIMITATIONS.md)。

### 6. 我的数据去哪了？

配置、记忆、审计日志默认只存在本机 `<dataDir>`；生成回复所需的消息内容与上下文会发给你自己配置的 LLM 服务商。项目无遥测。清单见 [PRIVACY.md](PRIVACY.md)。

### 7. 怎么卸载？会删我的聊天记录吗？

从 DSH profile 的 `dependencies` 与 `dsh.profile.bundles` 移除插件并重启即可，**不会删除微信聊天记录**。是否删除 `<dataDir>`（插件记忆/审计/草稿）由你决定，删除后不可恢复——建议先备份。

### 8. 怎么反馈问题？

用 Issue 模板，提供版本、环境、复现步骤、mock 结果与已脱敏日志；**不要**贴真实好友名、wxid、手机号、聊天截图、API Key、含用户名的完整路径。安全问题请走私密披露（[SECURITY.md](../SECURITY.md)）。

### 9. 和腾讯/微信官方是什么关系？

**没有任何关系。** 本项目是个人独立开发的免费开源实验项目，非官方、未获授权、不代表腾讯/微信。

### 10. 后续路线？

先把 beta 的真实环境验收、OCR 准确率、发送可靠性做扎实，再考虑稳定版；`fusion/align/tracker`、RapidOCR 新包、其他通道在验证后再接入。以发布草稿与 [BETA-LIMITATIONS.md](BETA-LIMITATIONS.md) 为准。
